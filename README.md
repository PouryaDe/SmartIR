# SmartLink (IR SmartLink)

SmartLink یک اسکریپت قدرتمند، بهینه و امن برای مدیریت و توزیع لینک‌های سابسکریپشن V2Ray/Xray است. 
این اسکریپت به شما اجازه می‌دهد تا ترافیک کاربران خود را به صورت هوشمند مدیریت کنید و از امکاناتی مانند کشینگ قدرتمند، تنظیمات پروکسی داخلی (SOCKS5)، و امنیت بالا بهره‌مند شوید.

## ✨ ویژگی‌های کلیدی

- **نصب کاملاً خودکار**: تمامی مراحل از نصب پیش‌نیازها تا تنظیمات SSL و Nginx با یک اسکریپت ساده انجام می‌شود.
- **کش قدرتمند (Caching)**: ذخیره پاسخ‌های API برای کاهش بار روی سرور اصلی و افزایش چشمگیر سرعت (اختصاصی برای هر دامنه).
- **پشتیبانی از SOCKS5 Proxy**: امکان ارسال درخواست‌های سرور به API اصلی از طریق پروکسی برای دور زدن محدودیت‌های شبکه.
- **تشخیص هوشمند User-Agent**: ارسال کانفیگ به کلاینت‌های VPN (مثل V2rayNG, V2Box, Streisand) و هدایت (Redirect) مرورگرها و ربات‌ها به آدرس دلخواه.
- **مدیریت چند دامنه (Multi-Domain)**: امکان افزودن، حذف، و مدیریت چندین دامنه مختلف به طور همزمان روی یک سرور.
- **امنیت بالا**: جلوگیری از Path Traversal، حملات XSS و محافظت از فایل‌های حساس توسط تنظیمات خودکار Nginx.

## 🚀 راهنمای نصب سریع (پیشنهادی)

برای نصب، آپدیت و مدیریت سایت‌ها، تنها کافیست اسکریپت نصب آسان ما را اجرا کنید. این اسکریپت روی سرورهای **Ubuntu** طراحی و تست شده است.

دستور زیر را کپی کرده و در ترمینال سرور خود (با دسترسی root) وارد کنید:

```bash
wget -O install.sh https://raw.githubusercontent.com/PouryaDe/SmartIR/main/install.sh && chmod +x install.sh && sudo ./install.sh
```

### امکانات منوی مدیریت:
پس از اجرای دستور بالا، با یک منوی تعاملی و زیبا روبرو می‌شوید:

1. **Install Prerequisites**: نصب پکیج‌های مورد نیاز (Nginx, PHP 8.1, Certbot, Git) - *فقط یک‌بار در یک سرور خام نیاز است.*
2. **Add a New Site**: اضافه کردن یک دامنه جدید، دریافت گواهینامه SSL خودکار و تنظیم پروژه.
3. **List Sites**: مشاهده دامنه‌های فعال روی سرور.
4. **Delete a Site**: حذف کامل یک دامنه (فایل‌ها، Nginx و گواهینامه SSL).
5. **Update Source Code**: به‌روزرسانی کد پروژه از مخزن گیت‌هاب بدون از دست رفتن تنظیمات فعلی.
6. **Clear Cache**: پاک کردن کش یک سایت خاص در صورت نیاز به آپدیت فوری کانفیگ‌ها.
7. **Configure Proxy**: تنظیم پروکسی (SOCKS5) اختصاصی برای سایت مورد نظر جهت ارتباط با سرور API اصلی.

## ⚙️ ساختار پروکسی (SOCKS5)

اگر سرور واسط شما در دسترسی مستقیم به سرور API مشکل دارد (مثلاً فیلترینگ یا تحریم)، می‌توانید از گزینه `Configure Proxy` در منوی نصاب استفاده کنید. 
فرمت استاندارد پروکسی باید به شکل زیر باشد:
```
socks5://USERNAME:PASSWORD@PROXY_IP:PORT
```
*نکته: در صورت نداشتن یوزرنیم و پسورد، بخش مربوطه را حذف کنید: `socks5://PROXY_IP:PORT`*

## 🛠️ نکات فنی و امنیتی

- **مدیریت کش**: کش‌ها به صورت خودکار هر ۵ دقیقه منقضی می‌شوند تا جدیدترین تغییرات پنل و دیتابیس دریافت شود.
- **حفاظت از فایل‌ها**: دسترسی مستقیم تحت وب به پوشه `/cache` و فایل‌های حیاتی (مثل `config.php`، `Route.php` و `.log`) توسط Nginx کاملاً مسدود شده است.
- **تیونینگ خودکار**: اسکریپت نصاب به صورت هوشمند مقادیر Nginx و PHP-FPM را بر اساس تعداد هسته CPU و رم آزاد سرور شما محاسبه و بهینه می‌کند.
